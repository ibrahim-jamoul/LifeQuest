# Décisions produit — référence V3 (11/10/2026)

1. **Orientation : PORTRAIT (verticale).** Cette décision corrige et annule toutes les anciennes mentions « horizontal / paysage ». Cible : smartphones et tablettes tactiles, ordinateur hors priorité MVP.
2. Site / web-app installable depuis la page d'accueil : option PWA, modalités d'installation dépendantes d'HTTPS et du navigateur.
3. Design : ressembler à un jeu, cubique/low-poly simple, arrière-plan spatial saison 1. Refuser les mises en page de type tableau de bord SaaS ; éviter les graphismes 3D complexes au MVP.
4. Parcours entrée : chargement → titre/Jouer → profils → avatar → Nova (robot mascotte, design à approfondir) → lobby.
5. Lobby unique et segmentation directe en cinq espaces **École / Cadeaux / Concentration / Découverte / Parents**. Ce ne sont PAS les matières scolaires ni Nature/Sciences/etc.
6. École : matière → chapitre → notion → cours vidéo court obligatoire (1 à 2 min maximum) + cours écrit optionnel → quiz/mini-jeux/autres activités → résultats/progression. Le cours doit précéder le déblocage des activités ; il reste révisable.
7. Matières/chaps/notions : structurer le programme 6e avant l'industrialisation des médias. Distinguer éléments de référentiel et contenus disponibles.
8. Cadeaux : récompenses virtuelles + cadeaux réels envisagés ; cadeaux réels soumis à validation parentale. Ne pas automatiser achat/livraison ; ne pas simuler une autorisation réelle.
9. Concentration : à construire dès le MVP ; mécanismes définitifs non arrêtés — le minuteur fourni est une hypothèse de prototype, **pas une décision fonctionnelle validée**.
10. Découverte puis Parents : développement ultérieur, dans cet ordre ; pas de scènes gameplay 3D pour le MVP scolaire.
11. Parents : accès avec PIN demandé dans le cadrage, mais sa conception/implémentation sécurisée est reportée avec le module complet ; la validation des cadeaux réels doit être interdite tant qu'un dispositif sûr n'existe pas.
12. Enfants 10–12 ans ; ne pas demander de vraies informations personnelles dans le prototype.
